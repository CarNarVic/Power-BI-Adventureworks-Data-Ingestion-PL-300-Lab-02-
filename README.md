# 🔄 AdventureWorks Data Transformation & Cleansing (PL-300 Lab 02)

## 📌 Project Overview
This project covers the data cleansing and transformation phase using **Power Query** as part of the official Microsoft PL-300 (Power BI Data Analyst) certification labs.

The primary goal was to process raw dimensional and transactional data from the `AdventureWorksDW2020` database, remove unneeded columns, clean data types, and shape the dataset into a structured format ready for analytical modeling.

---

## 🛠️ Tech Stack & Tools
- **Power BI Desktop** (Power Query Editor)
- **SQL Server 2025** (Data Source)
- **AdventureWorksDW2020 Database** *(Based on official Microsoft PL-300 Labs)*

---

## 🚀 Key Tasks Completed
1. **Column Management:** Filtered and removed unnecessary columns to optimize data structure (e.g., in `DimProduct`, keeping only essential attributes like `ProductKey`, `EnglishProductName`, `StandardCost`, `Color`, and subcategories).
2. **Data Cleansing & Validation:** Verified and adjusted data types across tables to ensure accuracy and optimal performance for upcoming calculations.
3. **Power Query Automation:** Applied structured transformation steps to build a clean, repeatable data preparation pipeline.

---

- `DimProduct`
